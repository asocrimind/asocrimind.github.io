ASOCRIMIND

## Descripción

El proyecto está pensado para ser una página informativa, 
de momento solo presenta información relevante para la 
organización ASOCRIMIND. 
Nota: está en línea usando github pages.

## Objetivo

El objetivo principal es organizar la información para que
el cliente pueda obtenerla de manera sencilla y fácil de entender.

## Características

- Index: es el inicio de la página, aquí se presenta información de la empresa.
- Nosotros: se presentan los perfiles de cada integrante en la empresa.
- Servicios generales: se presentan los servicios directos de la institución.
- Servicios periciales y servicios en informática: se presenta información sobre servicios del colaborador.
- Productos: se presenta el catálogo de productos y cómo pedir uno.
- Convenios y colaboraciones: se presentan las empresas vinculadas a la empresa.
- Contacto: se presentan los datos para ponerse en contacto con la empresa.

## 🛠️ Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Git / GitHub
